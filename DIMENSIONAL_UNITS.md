# Dimensional Units

This file defines the dimensional vocabulary for this codebase.
Generated by dimensional-analysis plugin.

## Base Units
- `{USDC}` - Asset token amounts: vault assets, bet stakes, payouts, deficit, reserved liquidity, house PnL
- `{credit}` - Player credits held by Roulette, redeemable 1:1 for USDC (identity conversion, alias of `{USDC}`)
- `{share}` - RouletteVault ERC4626 LP shares
- `{s}` - Seconds: absolute timestamps and durations
- `{1}` - Dimensionless: payout multipliers (D0) and bps ratios (BPS)
- `{count}` - Number of bets

## Derived Units
- `{USDC/share}` - Vault share price (implicit in ERC4626 `_convertToShares` / `_convertToAssets`, virtual offset 10^6)
- `{USDC/USDC}` = `{1}` - Payout multiplier: stake → winnings (`mult`) or stake → gross payout (`mult + 1`)
- `BPS{1}` - Fraction in basis points: `maxExposureBps` (net round worst case / vault assets)

## Precision Prefixes
- `D6` - 1e6: USDC, credits, every bet / payout / PnL / deficit / capacity amount
- `D12` - 1e12: vault shares (USDC 6 decimals + `DECIMALS_OFFSET` 6)
- `BPS` - 1e4: `maxExposureBps`, `BPS = 10_000`
- `D0` - 1: integer payout multipliers, counts

## Not quantities
- `{pocket}` - Wheel index 0..36 (`winningNumber`, bet numbers)
- `{mask}` - 37-bit coverage bitmask (`numbersMask`, `*_MASK`)
- `{id}` - Identifiers: roundId, betId, requestId
- `{gas}`, `{block}` - VRF callback gas limit, request confirmations

## Naming hazards
- `Round.totalBets` is `D6{USDC}` (sum of stakes); `PlayerStats.totalBets` is `{count}`
- Gross vs net: `Round.totalPayout`, `totalPaidOut`, `payout` include the stake; `PlayerStats.totalWon` excludes it
